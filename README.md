# 社交媒体内容传播数据分析

## 项目目标
整理内容浏览及互动指标，展示对公开传播数据的清洗、脱敏、缺失值处理和结果解释能力。

## 展示重点
- 数据脱敏：仅保留匿名编号和区间化指标，不公开平台、账号、原文或链接。
- 指标整理：统一浏览、点赞、评论、转发、分享等互动字段。
- 缺失处理：对未知数据留空，不将缺失值误判为 0。
- 分析边界：基于小样本做描述性观察，不做过度推断。

## 数据说明
本仓库仅提供**经过区间化、匿名化处理的展示数据**，不包含平台、账号、内容原文、发布时间或可定位链接。区间数据不用于精确还原单条帖子的真实指标。

## 数据字段
- `content_id`：匿名编号
- `views_band`：浏览量区间；未知则留空
- `likes_band`：点赞量区间
- `comments_band`：评论量区间
- `reposts_band`、`shares_band`：转发、分享区间；未知则留空

## 方法与限制
- 使用区间数据描述传播规模，不使用区间端点计算精确互动率。
- 对缺失数据留空，不当作零。
- 仅有两条内容，不能据此推断平台算法、稳定增长或选题效果。

## 文件
- `data/content_metrics_anonymized.csv`：脱敏区间数据
- `analysis_report.md`：结果说明与局限

## 适用场景
该项目可作为数据整理、基础分析和隐私保护意识的作品集示例。
